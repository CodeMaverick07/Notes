Windows Booting Process: A process of starting computer(initializing OS) is called booting process.
========================
Types of booting: Cold Booting	-- system was off, and then powered on
		  Warm Booting	-- system is running state, and you restarted it due to some reason.

Booting Process Steps:
----------------------
Power On
POST (Power-On Self-Test)
BIOS/UEFI
Bootloader
Windows Boot Manager
Windows OS Loader
Kernel Initialization
Session Manager
Winlogon
User Logon
User Profile Load
Startup Programs


1. Power On:

2. When you turn on your computer, the power supply sends power to all components.
POST (Power-On Self Test):

3. The BIOS/UEFI performs a POST to check the hardware components (CPU, RAM, etc.) are functioning correctly.
BIOS/UEFI Initialization:	Unified Extensible Firmware Interface

BIOS/UEFI firmware is loaded and initializes system hardware.
It locates the boot device (HDD, SSD, USB, CD/DVD etc.) containing the operating system.

4.Boot Loader Execution:

The BIOS/UEFI hands over control to the boot loader (Windows Boot Manager) located on the boot device.


5.Windows Boot Manager (bootmgr):

The boot manager is loaded and it reads the Boot Configuration Data (BCD) to determine the operating system to boot.

6.Winload.exe:

Windows Boot Manager loads winload.exe, which is the Windows OS loader.

7.Kernel Loading:
Kernel is an imp component of every OS, heart of an OS.
manages 
CPU mgmt.
Memory mgmt.
I/O mgmt.
Process mgmt.
devices mgmt.

winload.exe loads essential drivers and the Windows kernel (ntoskrnl.exe) into memory.


8.Hardware Abstraction Layer (HAL):

HAL (hal.dll) is loaded to provide a layer between the hardware and the software.


9.System Registry Loading:

The system registry is loaded into memory.


10.Session Manager Initialization (smss.exe):

The Session Manager process starts and initializes system sessions, loads the Windows subsystem, and configures the environment for the user sessions.


11.Winlogon and LogonUI:

winlogon.exe starts and loads the login screen (LogonUI), waiting for user credentials.


12.User Logon:

The user enters their credentials, and if authenticated, the user profile is loaded.


13.Desktop Environment:

The Windows desktop environment and shell (explorer.exe) are started, allowing user interaction with the system.
Once these steps are completed, the system is ready for use.

Booting Process – Windows Server 2016 with BIOS Firmware
1.	Power On / POST (Power-On Self Test)
	a. System powers on, BIOS initializes CPU, memory, and hardware components.
	b. BIOS checks for bootable devices in the configured boot order (HDD, SSD, DVD, PXE, etc.).


2.	MBR (Master Boot Record) Execution
	BIOS loads the first sector (512 bytes) of the boot disk into memory.
	MBR contains:
		a. Boot loader code.
		b. Partition table.
		c. MBR code passes control to the Volume Boot Record (VBR) of the active partition.

3.	Bootmgr (Windows Boot Manager)
		The MBR locates and starts Bootmgr.exe.
	Bootmgr is responsible for:
		a. Reading the BCD (Boot Configuration Data) store.
		b. Presenting the boot menu (if multiple OS/boot entries exist).

4.	BCD (Boot Configuration Data) Processing 
		a. Bootmgr reads BCD store (located in \Boot\BCD on system reserved partition).
		b. It determines which OS to boot and passes instructions accordingly.

5.	Winload.exe (Windows OS Loader)
		Bootmgr loads Winload.exe, which is responsible for:
				a. Loading the kernel (Ntoskrnl.exe).
				b. Loading HAL (Hardware Abstraction Layer).
				c. Loading essential boot-class drivers.
				d. Loading system registry hive.

6.	Kernel Initialization (Ntoskrnl.exe)
		a. Initializes memory manager, scheduler, and device drivers.
		b. Starts the Session Manager Subsystem (smss.exe).

7.	Session Manager Initialization (smss.exe)
		a. Loads system environment variables.
		b. Starts Wininit.exe (Windows Initialization process).

8.	Wininit.exe Initialization:
	It launches:
		a. Services.exe (Service Control Manager).
		b. Lsass.exe (Local Security Authority Subsystem).
		c. Winlogon.exe (handles user logon).

9.	Logon Screen (Winlogon.exe)
		a. Displays logon UI.
		b. User authentication occurs via Lsass.
		c. After login, Windows Server 2016 desktop or Server Manager loads.
Summary:
=======
POST → MBR → Bootmgr → BCD → Winload.exe → Ntoskrnl.exe → Smss.exe → Wininit.exe → Services.exe + Lsass.exe + Winlogon.exe → Logon Screen

File System:
		
1. Index of an operating system
2. A file system is the method Windows uses to store, organize, manage, and retrieve files and folders on storage devices
3. It provides a hierarchical structure of files and directories.

Types of files system:
=====================
1. FAT         FAT8   FAT12     FAT16    FAT32
2. NTFS
3. ReFS
4. ExFAT

FAT16:		 File Allocation Table 16
====
1. Maximum Volume Size: Typically up to 2 GB (some implementations support up to 4 GB)
2. Simple and easy to implement	


	
FAT32:  File Allocation Table 32
=====
1. Lightweight and simple
2. Supported by Windows, Linux, macOS, cameras, gaming consoles, and USB devices.
3. Maximum file size: 4 GB.
4. Maximum Partition size 32GB.
5. Easy implementation.
6. Does not support advanced security features such as file permissions and encryption.
	

NTFS (New Technology File System) is the default file system in modern Windows because it provides:
=================================
1. Supports  upto 2TB partition size 
2. File and folder permissions
3. Encryption (EFS)
4. Compression
5. Disk quotas
6. Large file and volume support
7. Better reliability and recovery through transaction logging.

ReFS	Resilient File System:
=============================

1. Developed by Microsoft.
2. Provide data integrity, scalability, and protection against data corruption.
3. Commonly used in Newer Windows Server and enterprise storage environments.
4. Supports very large volumes and files.
5. Best for automatic corruption detection and repair.



ExFAT	Extended FAT:
====================

1. Designed for USB drives, SD cards, memory cards, and external hard drives.
2. Supports files larger than 4 GB, unlike FAT32.
3. Compatible with Windows, macOS, and many other devices.
4. Optimized for flash storage devices
