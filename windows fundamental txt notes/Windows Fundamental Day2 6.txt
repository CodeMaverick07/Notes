Registry:		regedit				registry editor

1. The Windows Registry is a critical component of the Windows operating system
2. Acting as a centralized repository for configuration settings.
3. It contains information about hardware, software, user preferences, and system settings.
4. When a program is installed, it typically adds entries to the registry that specify its configuration, file 	locations, and other operational parameters. 

Main components are:

1. Hives: These are the top-level sections of the registry, such as HKEY_LOCAL_MACHINE and HKEY_CURRENT_USER, 	which categorize the data stored within.

2. Keys: These are similar to folders and can contain subkeys and values. Each key can hold various settings  	related to the system or applications.

3. Values: These are the actual data entries within keys, which can be strings, numbers, or binary data.

1. To delete run menu history in Windows 10/server 2016

a. Press Win+R to open the Run window. Type regedit and hit Enter to open the Registry Editor.

b. HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\RunMRU

c. In the right panel, you will find the entire history. Select all the strings except the Default string and delete them.

2. To start notepad & calculator automatically at user login:

a. Press Win+R to open the Run window. Type regedit and hit Enter to open the Registry Editor.
b. HKEY_Local_Machine---Software---Microsoft---Windows--Current Version---Run--- Right Click in right pane, new---> String value --np
c. Right click on np---modify--notepad.exe
d. Right Click in right pane, new --->String value --calculator.
e. Right click on calculator---modify--calc.exe
f. logoff and login again as administrator, notepad and calculator should open automatically.

3. To change the appearance of search button on taskbar of Windows 2016:

1. Browse to the following path: HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Search.
2. Right Click on Search, select New - DWord Value (32bit)
3. Enter the name SearchboxTaskbarMode and press enter
4. Double-click the SearchboxTaskbarMode key and set its value to 0. ...
5. Click the OK button.

To verify :  Sign out----Sign as administrator and see taskbar for search button

To enable search:
Double click SearchboxTaskbarMode and then set the Base to Hexadecimal and the Value data to 2. Click OK to save changes.

0 = Hidden 
1 = Search bar icon
2 = search bar box.

4. Disabling the Entire control panel:

1. Start the Registry Editor.
2. Navigate to the path below,
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer
3. Right-click on the empty space and click New > DWORD (32-bit) value.
4. Name the new DWORD as NoControlPanel.
5. Right-Click on NoControlPanel > Modify.
6. Set the Value as 1 to Disable the control panel and 0 to Enable the control panel back.
7. We can also delete the DWORD to enable the control panel back again.

6. Disable Command Prompt for Current User:

Use HKEY_CURRENT_USER (HKCU) to apply a policy for only the logged-in user.
Steps:
Open Registry Editor.
1.	Navigate to:HKEY_CURRENT_USER\Software\Policies\Microsoft\Windows\System
2.	If the key doesn’t exist, create it. RC on Windows, New—Key--System
3.	RC on System—New--- DWORD (32-bit) Value named:  DisableCMD
4.	Set its value to 1.
5.	Verify by Log off and log in again.
When you open Command Prompt, you’ll see the message:
"The command prompt has been disabled by your administrator."

To enable cmd, change the value to 0, or delete the DWORD(DisableCMD).

Event Viewer:		run:	eventvwr.msc			
The (Windows) Event Viewer shows the event logs of the system

Four Windows event log types:

1. System:      contains events related to the system and its components. Failure to load the boot-start driver is an example of a system-level event.

2. Application: Events related to a software or an application.
		For example, the problem in starting Microsoft PowerPoint comes under the Application log.

3. Security: contain events related to the safety of the system. logon success/failure, object access.

4. Setup:       Setup log contains events that occur during the installation of the Windows operating system

=========

Services:
	1. A service is a small program that usually starts when the Windows operating system loads. 
	2. You won't normally interact with services like you do with regular programs because they run in the background (you don't see them) 		    and don't provide a normal user interface


To set the Startup type of a Windows service to be: 
1. Automatic: the service starts at boot time. 
2. Automatic (Delayed Start): the Windows service starts only after the system has loaded all the other services set to start automatically.
3. Manual: the Windows service starts only when it is needed. 
4. Disabled: the service never starts, even when its operation is requested by other Windows services or apps.
