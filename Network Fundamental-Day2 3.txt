Proxy Server

1. Proxy helps in fast access to the data that has been accessed very often.
2. Saves Bandwidth.
3. Proxy server is used to encrypt your web requests.
4. Proxy server is used to control and monitor how their employees or kids use the internet. 

Types of Proxy Servers:

1. Reverse Proxy Server:
=======================
1. It accepts requests from clients and forwards them to the appropriate server. 
   It also receives responses from the server and sends them back to the client.

2. A forward proxy is the designated exit point for network users seeking to connect with resources outside their   private network.


A forward proxy sits between a client and the internet

A reverse proxy sits between a client and a server.

A forward proxy is primarily used to provide privacy to the client and bypass network restrictions. 

A reverse proxy is used mainly to improve the server’s performance, security, and scalability.
