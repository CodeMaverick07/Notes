Shell:

1. A shell is a command-line interpreter that acts as the interface between the user and the Kernel (operating system).
2. It allows users to interact with the OS by typing commands and executing programs.
3. Shells are also used for scripting, where sequences of commands are stored in a file and executed automatically. 

1. Bourne Shell (sh):   The original UNIX shell.
2. Bourne Again Shell (bash): The most widely used shell in Linux and macOS.
3. C Shell (csh)
4. Korn Shell (ksh)
5. Z Shell (zsh)
6. TENEX C Shell (tcsh)

Working with shells:
#cat /etc/shells

Print active shell name:
#echo $SHELL

=================================================================
Shell Scripting:
1. A shell script is a text file that contains a sequence of commands for a Linux/Unix-based operating system 	(OS). 

2. A shell script is usually created to save time for command sequences that a user needs to use repeatedly.
3. Shell scripting is a way to automate tasks in an operating system by writing a script .
==================================================================================

Shell Variables:

1.	A shell variable is a character string in a shell that stores some value. 
2.	It is a pointer to the actual data stored in memory.
3.	A variable name could contain any alphabet (a-z, A-Z).
4.	Any digits (0-9).
5.	An underscore ( _ ). 

Rules for variable definition:

1.	A variable name must start with an alphabet or underscore. 
2.	It can never start with a number and special characters except  _ underscore because all other special characters  	have special meanings in Shell Scripting.

Valid Variable Names
a.	XYz
b.	_AF_5
c.	BC232

Invalid Variable Names 
a.	2_PQ
b.	!MNZ
c.	$QWE
d.	&XX22

                echo " your number is greater than 100"
elif     [   $n  -lt  100  ]

                echo " your number is less than 100"

                echo " your number is equal to 100"

Shell Script with a Case Statement:

1. Case statements allow you to manage multiple possible outcomes based on the value of a single variable.
2. It simplifies complex conditions with multiple choices, making it more readable and easier to maintain than nested if statements.
3. The Bash case statement is a form of the conditional if-elif-else statement.
4. Structured way to handle multiple choices or patterns for a given value.


#vim case-test.sh
#!/bin/bash

read -p  "Enter a number between 1 and 3:  "  n 

case $n in
    1|one)
        echo "You selected One."
        ;;					# ;;  break
    2|two)
        echo "You selected Two."
        ;;
    3|three)
        echo "You selected Three."
        ;;
	
     *)
        echo "Invalid selection. Please enter 1, 2, or 3."
        ;;
esac

#chmod +x case-test.sh
#sh case-test.sh

Case Statement with Multiple Matches:
1. The Bash case statement is a form of the conditional if-elif-else statement.
2. Structured way to handle multiple choices or patterns for a given value.


#vim weekday.sh
#!/bin/bash
echo "Enter a day(Mon|Tue|Wed|Thur|Fri|Sat|Sun): "  
read day

case  $day  in
    Mon|Tue|Wed|Thur|Fri)
        			echo "It's a weekday."
        ;;
    Sat|Sun)
       				echo "It's the weekend!, Enjoy!!!"
        ;;
    *)
        echo "Not a valid day."
        ;;
esac

File Test: These operators are used to test a particular property of a file.

File test operators in Bash
-e file: Checks if file exists. Returns true if the file or directory exists.
-f file: Checks if file is a regular file (not a directory or special file). 
-d directory: Checks if directory exists and is a directory.
-s file: Checks if file exists and has a size greater than zero (is not empty).
-r file: Checks if file exists and is readable by the current user.
-w file: Checks if file exists and is writable by the current user.
-x file: Checks if file exists and is executable by the current user.
-b file: Checks if file is a block special file.
-c file: Checks if file is a character special file.
