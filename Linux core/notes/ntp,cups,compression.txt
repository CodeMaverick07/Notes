The xinetd daemon: (/etc/xinetd.conf). you need to install xinetd package first.
1. In Linux, the extended Internet services daemon (xinetd) replaced inetd. 
2. It performs the same function as inetd in that it listens to multiple ports and invokes a requested service. 
3. It is more secure.
4. Typical xinetd services include Remote Shell (RSH), FTP, telnet, and Post Office Protocol 3 (POP3).
	It’s also common to run the HTTP, sendmail and Samba services as standalone daemons.

NTP: Network Time Protocol  udp/123

Network Time Protocol is a protocol that allows the synchronization of system clocks (from desktops to servers).
Time synchronization between all domain joined systems/network system is very important to record logs with accurate date/time, logging to domain, for various distributed applications etc.

Compression/Decompression tools:
===============================
1. gzip (the most commonly used (GNU zip))	
	#cd
	#ls -lh
To compress a file install.log:
	#gzip install.log
	#ls -lh

To see the content of a compressed file(.gz)
	#zcat install.log.gz
To decompress:
	#gunzip install.log.gz
	#ls -lh
	

2. bzip2 -----offers better compression but slower speeds than gzip. 	
	#cd
	#ls -lh
To compress a file install.log:
	#bzip2 install.log
	#ls -lh
			install.log.bz2

To see the content of a compressed file(.bz2)
	#bzcat install.log.bz2

To decompress:
	#bunzip2 install.log.bz2
	#ls -lh


3. xz which provides the highest compression ratio but slowest. Suitable for archiving large   250MB

# Compress a file:
		#xz install.log
		#ls -lh

		#xzcat install.log.xz


# Decompress a file:
		#unxz install.log.xz

Backup in Linux:  making the duplicate copies for important data so that can be used to recover the original data in case of accidental deletion or data corruption. 

Types of Backup: 
1. Data backup
2. System Backup

Types of data backup:
1. Full backup				takes backup of all files(A enabled/without A)
					clears the A bit after taking backup

2. Incremental Backup:			are taken only after full backup
					it will take backup of all files(a enabled) since last backup
					clears the A bit

3. Differential backup			are taken only after full backup
					does not clear the A bit after taking a backup
					it will take a backup of all files(a enabled) since last full backup



Backup type			Date backed up						Backup time
==========			==============						===========
1. Full backup			All imp							Slowest
2. Incremental backup		Only new/modified files and folders			Fast
3. Differential backup		All imp since last full					Moderate

1. tar------> tape archive
Tar is primarily used for packaging multiple files and directories into a single file.


How to take a backup using tar:

#mkdir /imp
#cd   /imp
imp]#touch a b c 
imp]#mkdir imp  confidential
#cd /
#mkdir /backup

To take backup:
#tar -cvf /backup/imp.tar    /imp
#ls -lh /backup

To take compressed backup using gzip:
#tar -cvzf /backup/imp.tar.gz    /imp
#ls -lh /backup

To take compressed backup using bzip2:
#tar -cvjf /backup/imp.tar.bz2    /imp
#ls -lh /backup

To view the compressed file imp
#tar -tvf /backup/imp.tar

To restore :
#tar -xvf /backup/imp.tar
#ls /imp
=========================================================================================
to restore compressed backup using bzip2
#tar -xvjf /backup/imp.tar.bz2

to restore compressed backup using gzip
#tar -xvzf /backup/imp.tar.gz
