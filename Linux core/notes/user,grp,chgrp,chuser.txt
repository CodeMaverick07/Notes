Working with Users & Groups

Types of users:							UID		GID
1. Super User			root				0		0	
2. Built-IN Users		system Users			1-999		1-999
3. Standard/Normal Users	Users created by admin root	1000-60000	1000-60000


when you create a user

useradd prem

1. system will create user			prem
2. system will create primary group		prem
3. system create home folder			/home/prem
4. will disable account		


files associate with users/group

/etc/passwd		contains users list(uid, gid, login name home folder, shell name)
/etc/group		contains group lists (group name, gid, member details)
/etc/shadow		contains passwords (encrypted format)
/etc/gshadow		user settings/profile

Sudoers		sudo user-------- a user with specific admin rights/privileges, so that user can perform administrative tasks without having root pwd.

To generate a line number in vi:
===============================
esc: se nu


To remove line number in vi:
===========================
esc: se nonumber


#useradd jane
#passwd jane

 To make jane a sudo user(admin right):
#vi   /etc/sudoers			read only file
OR
#visudo

esc:se    nu				to generate line number


goto line 99
jane		All=(ALL)	ALL

esc:wq			save
