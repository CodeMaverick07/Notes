sed:  String Editor-------perform lots of functions on file like find & replace, insertion & deletion.

1. To replace red with grey of file colors.txt     (changes will be displayed on terminal, but will change inside the file)

	#sed 's/red/grey/'  colors.txt			

2. To replace red with grey inside file colors.txt       (to replace data in a original file)

	#sed -i 's/red/grey/'  colors.txt	

3. #cat>OS.txt
Unix is great os. unix is opensource. Unix is free os.
Unix is cli based os. Unix is powerful.
Unix is easy to learn. Unix is a multiuser os. Learn Unix 

a. To replace only the 2nd occurrence of a word in a line: 
	#sed 's/Unix/Linux/2' OS.txt


b. To replace all occurrences of a word in a line: 
	#sed 's/Unix/Linux/g' OS.txt




4. To display the first 5 lines of a file:
	 #sed -n '1,5p' filename
			1,5: Specifies the range of lines to be printed (from line 1 to line 5). 
			p:   tells sed to print the specified lines. 

Note: If you use -n alone without p, then the sed does not print anything.

5. Printing Only the Replaced Lines
	# sed -n 's/unix/linux/p' f1.txt

6. To Delete a last line

	# sed '$d' f1.txt

7. Insert Text in a file:

	#sed '3i\new text' city.txt  # Insert text before line 3

Find & Locate command in Linux:  used to find/search a folder/files in a Linux system

Nautilus:  is the file manager for the GNOME desktop. It allows one to browse directories, preview files.

find command is used to find files/folders in Linux system.

1. To find file inittab in entire file system
		#find / -name inittab

	
2. To find file passwd in entire file system(ignore case)
		#find / -iname passwd

3. To find files which are empty in /root directory
		#cd
		~]#find . -type f  -empty
 
4. To find files which are empty not in /root directory
		#cd
		~]#find . -type f  ! -empty					f-->file

5. To find all folders named as London in entire file system
		~]#find / -type d -iname London					d-->directory


6. To find files whose size is more than +10KB in /root
		#cd
		~]#find . -size +10k	



7. To find files whose size is more than 10MB & less than 60MB in /root
		~]#find . -size +10M  -size  -60M

	

8. To find all files having extension .txt in entire file system
		~]#find / -type f -iname  "*.txt"

9. To find all files having extension .txt  and starting with a character in entire file system
		~]#find / -type f -iname  "a*.txt"

10. To find all files whose permission is set as 777 in /root
		~]#find / -type f -perm 0777 -print
