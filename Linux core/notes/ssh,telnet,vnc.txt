SeLinux		Security Enhanced Linux----	advanced security in Linux  it is a predefined Security policies, allows administrators to have 						more control over who can access the system.

modes of SeLinux:
1. disabled					No SELinux policy is loaded
2. Permissive  	allow 		 (create logs), Prints warnings instead of enforcing
3. Enforcing  (default)		  create logs,  deny, Enforces the SeLinux security policy


To change the mode of SELinux temporarily:
#setenforce 0			0-->permissive  1-->enforcing
To see the status:
#getenforce
#sestatus

To change the mode of SELinux permanently:
========================================
#vim /etc/sysconfig/selinux
SELINUX=enforcing 
    OR
SELINUX=permissive
    OR
SELINUX=disabled
esc:wq

#reboot			to apply the effect

Working with Firewall:		Information is stored in the /etc/firewalld/firewalld.conf file.
1. To know if Firewalld is running:

	 # systemctl status firewalld
	OR
	 # firewall-cmd --state

2.To get the default zone:

	# firewall-cmd --get-default-zone

3. To get the list of zones:

		# firewall-cmd --get-active-zones

4. To get the list of all the available zones:

	# firewall-cmd --get-zones


5. To change the default zone to home permanently:

	# firewall-cmd --set-default-zone=home

6. To permanently assign the ens33 network interface to the internal zone:

	# firewall-cmd --permanent --zone=internal --change-interface=ens33

7. To know which zone is associated with the ens33 interface:

	# firewall-cmd --get-zone-of-interface=eth0

8. To add a source (here 192.168.2.0/24) to a zone permanently:

	# firewall-cmd --permanent --zone=trusted --add-source=192.168.2.0/24
	# firewall-cmd --reload

9. To only allow connections to your system from a specific IP address (here 1.2.3.4/32).

	# firewall-cmd --zone=internal --add-source=1.2.3.4/32 --permanent
	# firewall-cmd --reload

10. To add ssh service permanently: 
	# firewall-cmd  --zone=public --add-service=ssh --permanent
		or
	# firewall-cmd  --add-service=ssh --permanent
	# firewall-cmd --reload

11. To remove ssh service permanently: 
	# firewall-cmd --zone=public --remove-service=ssh --permanent
	# firewall-cmd --reload

12. To add several services (here http, https, and dns) at the same time:

	# firewall-cmd  --add-service={http,https,dns}  --permanent
	# firewall-cmd --reload

13. To get the list of services in the default zone:

	# firewall-cmd --list-services

The xinetd daemon: (/etc/xinetd.conf). you need to install xinetd package first.
1. In Linux, the extended Internet services daemon (xinetd) replaced inetd. 
2. It performs the same function as inetd in that it listens to multiple ports and invokes a requested service. 
3. It is more secure.
4. Typical xinetd services include Remote Shell (RSH), FTP, telnet, and Post Office Protocol 3 (POP3).
	It’s also common to run the HTTP, sendmail and Samba services as standalone daemons.

Logs: are reports generated by System Software (OS). In linux, default log location is /var/log
rsyslog port num  514 tcp/udp.

Main conf file:

	/etc/rsyslog.conf			

Types of logs:
=============
/var/log/messages----contains all logs
/var/log/secure---- contains authentication logs
/var/log/boot--- it contains boot related logs
/var/log/cron--- it contains cron related logs
/var/log/kernel--- it contains kernel related activities
