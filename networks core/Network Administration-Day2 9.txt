Uses default subnet mask /8, /16, or /24..

Classless Network:
Allows networks to use custom subnet masks, making more efficient use of IP addresses  /25 , /26, /28, /29, /30 etc.

CLSM / FLSM & VLSM

Constant Length Subnet Mask/ Fixed LSM  	using same subnet mask throughout the nw regardless of IP requirement

Variable Length Subnet Mask			different subnet mask in the network as per the IP requirement

						reduces the wastage of IP Addresses.

FLSM (Fixed Length Subnet Mask)
	a. Same subnet mask for all subnets
	b. Equal number of hosts
	c. Simple but wastes IP addresses

VLSM (Variable Length Subnet Mask)
	a. Different subnet sizes based on needs
	b. Efficient IP usage
	c. Flexible & used in modern networks

Collision Domain & Broadcast Domain:

Collision Domain: A logical network where data packets can collide with each other when sent on shared medium. eg HUB

Broadcast Domain: is a logical network where data sent by one device will be delivered to all other devices over that network.  example--Switch, Bridge



HUB			how many collision Domains			1 Collision Domain
			how many B'cast domains				1 B'cast Domain

Switch			how many collision Domains			Number of active port= number of Collision Domain
			how many B'cast domains				1 B'cast Domain


Bridge			how many collision Domains			Number of active port= number of Collision Domain
			how many B'cast domains				1 B'cast Domain
		

Router			how many collision Domains			Number of active port= number of Collision Domain
			how many B'cast Domains				Number of active port= number of B'cast Domain

Router Internal Components and Router Booting process:
1. ROM		POST, Mini IOS, Boot Loader, ROMMON (ROM Monitor---troubleshooting mode)
2. DRAM		Dynamic RAM		volatile RAM		temporary storage  			 running-config
3. NVRAM	Non-Volatile RAM	like Hard disk			permanent storage  (configuration files)   startup-config
4. Flash	Non-Volatile Memory	contains IOS		
5. Motherboard (Circuit Board)


Router Booting Process:

1. ROM----POST   (detects/check hardware available in a router, whether they are functional or not?)
2. Boot Loader----- look for IOS in  Flash	if available then it be copied into DRAM
						if not then  it will look for TFTP server (for IOS)
						if no tftp server available then router will enter into ROMMON mode


3. Once IOS is available, it will be loaded into DRAM.
4. Boot Loader will look for Saved configuration in NVRAM, if available----then file will be copied into DRAM
							   if no file available ---then it will enter into setup mode


		Configuration Register Value:  0x2102			Normal mode
					       0x2142			password recovery mode

IP Routing:
The process of transferring packets from source to destination through inter-network
it consists of two phases
		1. Identify the available networks in the topology, and define the best path to reach to that destination.
		2. Transferring the packets over the defined path.

	a. Routing is done manually by Administrator.

IP Routing:

Routing: is a process of transferring packets from source to destination through an internetwork

It consist of two tasks:
1. searching for the available nws & defining best path.
2. forwarding the packets over the defined path.


Types of Routing
1. Static
2. Default
3. Dynamic

Types of Routing:
1. Static 
				1. Administrator is responsible to define paths to reach to different nws
				2. More workload on administrator
				3. Less burden on Router's CPU and RAM (usage)
				4. More secure
				5. Administrator should have complete knowledge of internetwork topology
				6. Suitable for small internetworks
				7. Change in any nw leads to redefine entries in all routers for that nw.

Static routing can be done in 2 ways
1. Self exit method(directly connected)
2. Next Hop Method

Next Hop Method:
		
		#conf t
		config# ip route   <unknown nw>   <subnet mask>   <next hop ip>

Self exit method(directly connected)
		#conf t
		config# ip route   <unknown nw>   <subnet mask>   <Self Serial interface name>


To remove Static Routing:

conf t
config# no ip route  <unknown nw>   <subnet mask>   <next hop ip>
