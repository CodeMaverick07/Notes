Routing Metrics: Routing Metric is a value used by a routing protocol to determine the best path to a destination network 				when multiple routes are available.


1. Hop Count			Number of routers a packet passes through
2. Bandwidth			Link speed; higher bandwidth is preferred
3. Delay of line		Time taken for packet transmission(from source to destination)
4. Cost				Administrative value assigned to links
5. Reliability			Stability of a link		255/255--->reliable link
6. Load				Current traffic utilization on a link,1/255-->less traffic,255/255-->100% traffic congestion


7. MTU (Maximum Transmission Unit)  Max Ethernet frame size can be  1518 bytes, that can be transmitted over a network 					    without segmentation.			

1. RIP			Hop Count
2. IGRP & EIGRP		Bandwidth + Delay (Composite Metric)
3. OSPF & IS-IS		Cost (based on bandwidth)

RIP has four timers update, invalid, hold down and flush timer,

1. Update Timer (30 seconds): The interval at which the router sends its full routing table to neighbors.

2. Invalid/Timeout Timer (180 seconds): If no update is received for a route within this time, the route is considered invalid, and the metric is set to 16.

3. Hold-down Timer (180 seconds): Prevents a router from accepting less favorable, unstable routes for a specific period after a route is marked invalid.

4.Flush Timer (240 seconds): The time before an invalid route is completely removed from the routing table
