========================================================

Numbered ACL---Standard

Standard ACl:
1. preferably configured on Destination router.
2. can read / specify only source address.
3. can block entire network, cannot be used to block specific ip/port/service.


Extended ACL:
1. preferably configured on source router.
2. can read both source address & destination address
3. can be used to block specific ip, entire network, port/service.

Standard numbered ACL (creating rules):
======================================
config# access-list 1 deny host 192.168.1.2				explicit deny
	access-list 1 permit any		   			router will do implicit deny for all the traffic



to apply a acl rule: 									explicitly allow
 config# int s0/0
       # ip access-group 1 IN 

			OR

to apply a acl rule: 								
 config# int fa0/0
       # ip access-group 1 OUT

NAT	Network Address Translation		service/protocol--- Translates Private IP Add into Public IP Add and vice-versa

IANA---->IPs & ASN 

	Private IP 						Public IP
1.	local address					1. Global address
2.	unregistered add				2. registered address
3.	used in LAN(inside Organization) 		3. used over internet
4.	free of cost					4. buy ip from ISP
5. 	cannot carry data over internet			5. send data over internet


A 10.0.0.0--10.255.255.255				A	1-126

B 172.16.0.0-172.31.255.255				B	128-191

C 192.168.0.0-192.168.255.255				C	192-223

Types of NAT

1.Static					one to one mapping  (one pvt ip---one pub ip)		
2.Dynamic					dynamic mapping of pvt ip with public ip
3.PAT (NAT with Overload)			Multiple pvt ip ---one public ip
	Port Address translation

================================================================================================

2^32============= IPv4

Adv of NAT
1. Saves the available IP Address (IPv4)
2. Enhances security

Disadvantages:
1. NAT address translation leads to delay in data transmission.
2. All routers should support NAT who are used in Network.

1. Static					one-to one mapping
2. Dynamic					Pvt IPs are dynamically mapped with available public add
3. PAT (NAT with Overload)			multiple pvt add----->mapped with one or more public add

===================================================================================
Static NAT Configuration:

On ISP Router: static Routing
config# ip route 200.0.0.0 255.255.255.252 s0/0


ON NAT-Router: Default Routing
config# ip route 0.0.0.0 0.0.0.0 s0/0/1

ON NAT-Router:
config# int fa0/0
	ip nat inside			#to translate Public IP into Pvt IP
	exit
config# int s0/0/1
	ip nat outside			#to translate Pvt IP into Public IP
	exit
config# ip nat inside source static 192.168.1.66 200.0.0.1
config# ip nat inside source static 192.168.1.67 200.0.0.2

To verify NAT Table:
do show ip nat translations

To remove Static NAT entries:
============================
config# int gi0/0
	no ip nat inside			
	exit
config# int s0/0/1
	no ip nat outside			
	exit
config# no ip nat inside source static 192.168.1.66 200.0.0.1
config# no ip nat inside source static 192.168.1.67 200.0.0.2
